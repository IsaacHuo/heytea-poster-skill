## 1. 文字在画面里承担什么功能 [J]

| 功能 | 例 | 表现方式 |
|---|---|---|
| 讲一个想法（创意标题） | 0012 “琥珀色的，秋高气爽”；0235 “去茶底 纯享浓浓” | 手写，竖排或拆成两组左右对放 |
| 做画面本身 | 0114 “什组草台班子”铺满草地；0012 | 字面积 0.15–0.58 [M]，字形即构图 |
| 当旁白 / 注释 | 0234 “not to do list”、0322 “daze by inspiration 发呆” | 很小，贴近主体，像随手批注 |
| 指路 / 信息 | 0247 地图、0248 “喜茶就在后海A3出入口” | 信息准确，但以手写交付——功能与表现混合 |
| 讲笑话（自我修正） | 0201 coming soon→slowly、0043 划改 | 可见的修改痕迹本身是内容 |
| 功能信息 | 0104 活动日期、地址 | 小号规整字，放角落，几乎不参与表现 |

结论：**手写字在主线作品中承担的是“作者的声音”**；功能信息则安静地退到一边。两者不是字体类别，而是角色——0247 用手写字完成功能任务，0236 用规整印章字承担纯表现。

## 2. 拙趣为什么自然：拆解 [J]

观察 0009/0012/0235/0237/0238 的手写标题：

- **字号不等但有主次**：通常 1–2 个关键字明显大一号（“柿”、“浓浓”），其余字较小。变化不是每字随机，而是围绕语义重音。
- **基线是缓慢的波，不是抖动**：一行字的基线在 3–5 个字的跨度上只起伏一次左右；相邻字的偏移高度相关。
- **倾角少而统一**：多数字几乎直立，只有一两个字有明显倾角，通常在行尾或关键字。
- **笔画是单线、等粗偏细、末端圆**：马克笔/签字笔质感，没有毛笔的粗细变化；转折处略圆，偶有过冲。
- **结构“生涩”但不错**：部件比例略失衡（左右部件大小不一、竖画略斜），但部件位置正确；所以人能读，而 OCR 在边缘（见下）。
- **字距松**：字间距大于常规排印，留出呼吸；行距也偏大。

## 3. 一个可测量的旁证：OCR 在拙趣字上处于临界 [M]

对保留样本跑 RapidOCR（PP-OCR）：

- 0234 “龙井的” → “龙#的”；0295 “龙井芽前的故事” → “龙#芽前的故事”
- 0010 “‘柿’不简单” → “木市不简单”（左右部件分得太开，被读成两个字）
- 0043/0238 “看苏超” → “看苏趋”
- 0114 “什组草台班子” → “什想草台到班子”
- 规整功能字（0009 正文、0104 地址）全部识别正确

这说明喜茶的表现性手写**刻意停在“人能读、机器勉强能读”的位置**。因此：
1. 校验表现性文字时，不能要求 OCR 完全一致；采用“已知文本对齐”的字符相似度 + 阈值（legibility_threshold），并对每个字单独做结构保护。
2. 功能性文字必须 OCR 完全一致，作为硬门槛。
3. 部件分离（“柿”被读成“木市”）是最常见的失败形式 → 引擎对左右结构字限制水平拉伸与字内扰动幅度。

## 4. 可用字体调研（全部 SIL OFL 1.1，可商用可再分发）

| 字体 | 质感 | 适合角色 | 备注 |
|---|---|---|---|
| LXGW WenKai 霞鹜文楷 | 楷体，温和清晰 | functional 正文 / hybrid | 覆盖 GB2312+，繁体也有 |
| Noto Sans SC (variable) | 无衬线，中性 | functional 信息、价格、日期 | 可变字重 |
| ZCOOL KuaiLe 站酷快乐体 | 圆润、偏卡通 | expressive（俏皮） | 太“可爱”，强度高时偏幼稚 |
| Long Cang 龙藏体 | 随手行书，细笔 | expressive（随手、批注） | 最接近签字笔手写，但连笔会降低可读性 |
| Ma Shan Zheng 马善政 | 毛笔楷 | expressive（草台班子类） | 有粗细变化，与马克笔质感不符，少用 |
| Zhi Mang Xing 志莽行书 | 行书 | expressive（潦草） | 可读性最低，仅用于极短词 |
| ZCOOL XiaoWei 站酷小薇 | 文艺宋 | hybrid（安静、文艺） | |
| Liu Jian Mao Cao 刘建毛草 | 草书 | 不默认使用 | 可读性过低 |

喜茶真实的手写更接近“签字笔单线楷体，结构生涩”。开源字体里没有完全对应的，所以策略是：**以清晰字体作字形骨架（WenKai / KuaiLe / LongCang），由引擎施加“单线化 + 节奏扰动 + 结构保护”**，而不是挑一个已经很花的字体。

具体引擎设计见 [typography 引擎章节](#5-引擎设计) 与 `zhuoqu/typography.py`。

## 5. 引擎设计

见 README “文字引擎”一节；参数语义：

| 参数 | 含义（归一化到字号 em） |
|---|---|
| rotation_range | 单字最大倾角（度），但只有少数字被允许接近上限 |
| baseline_variation | 基线起伏幅度（em），由低频 1D 噪声生成，相邻字相关 |
| scale_variation | 字号变化幅度；语义重音字放大，其余由噪声微调 |
| spacing_variation | 字距变化（em） |
| stroke_irregularity | 轮廓低频形变幅度（em），用平滑 2D 噪声场位移控制点 |
| curve_softness | 轮廓转角圆化程度（形态学开闭 / 圆角描边） |
| width_variation | 单字高宽比变化 |
| line_break_strategy | none / balanced / semantic（按短语断）/ stagger（错位排） |
| density | 字距与行距的整体松紧 |
| legibility_threshold | 渲染后 OCR 相似度下限，不达标则自动降低强度重试 |
