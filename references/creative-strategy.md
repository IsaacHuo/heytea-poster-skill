# 创意策略

> 证据等级：**[M]** 像素测量（zhuoqu.analyze，可复现）；**[J]** 设计判断（可复核）；**[S]** 主观审美推断（需人工校准）。样本编号见 data/manifest.jsonl；语义标注为 agent_assisted / review_required。

## 1. 创意怎样形成 [J]

从样本反推，喜茶主线作品的创意大多是“**一个日常动作 + 一个不寻常对象**”：

| 手法 | 样本 | 句式 |
|---|---|---|
| 拟人（只加肢体） | 0237 杯子举起月亮 | 产品替人做了一件事 |
| 动作夸张 / 尺度反差 | 0248 小人推巨型杯子 | 小人 vs 大产品 |
| 生活化隐喻 | 0322 树下倒着一杯茶 = 发呆 | 抽象情绪 → 一个生活场景 |
| 视觉双关 / 文字游戏 | 0010 “柿”不简单；0114 “什组草台班子” | 用产品名改俗语 |
| 可见的修改 | 0201 soon → slowly；0043 划改 | 犯错/改口本身是笑点 |
| 味道抽象成色块 | 0236 | 口感 → 色彩关系 |
| 场景即画布 | 0190 围挡、0248 地铁灯箱 | 利用媒介所在的位置说话 |
| 素人作者 | 0270 名人儿童画 | 作者身份是创意 |

## 2. 稳定 vs 一次性 [J]

稳定：克制的元素数量、手写声音、实拍+手绘并置、俗语改写、动作化。
一次性：施工错字（依赖语境）、IP 造型（版权）、儿童彩铅（依赖作者）、2020 土味描边。

## 3. 规划器流程（creative_planner）

1. 解析：主题、产品、文案、氛围、比例、是否有照片。
2. 发散：至少 4 个**不同手法**的概念（同一手法只取一个），每个写出“一句话情节”。
3. 排除：落入禁用套路（笑脸水果、满屏涂鸦、无情节装饰、模仿 IP）的概念降分。
4. 评分：与氛围匹配、情节是否一句话说得清、能否由可用资源（模型/原语/照片）实现、与最近生成的多样性。
5. 产出：概念、隐喻、主体、插画元素、标题/辅文（带角色）、色彩、版式策略、参考及理由、模型提示词、文字参数。

## 4. 反模板清单 [S]

- 不给水果画脸；不默认画笑脸、星星、爱心。
- 每个手绘元素必须回答“它在情节里做什么”。
- 文案优先改写一个日常说法，而不是堆形容词。
- 安静主题时宁可少一笔。
