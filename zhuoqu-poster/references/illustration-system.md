# 插画系统

> 证据等级：**[M]** 像素测量（zhuoqu.analyze，可复现）；**[J]** 设计判断（可复核）；**[S]** 主观审美推断（需人工校准）。样本编号见 data/manifest.jsonl；语义标注为 agent_assisted / review_required。

## 1. 线条 [J]

- **单线、近黑、等粗**：0238、0322、0295、0247 都是签字笔粗细（约 0.4–0.8% 短边），无粗细变化；线色 #060505 / #0f0e0d / #121110 [M]。
- **低频抖动**：线条整体是平滑曲线上叠加一点慢速摆动（像手速较慢地画），没有高频锯齿。
- **闭合不严**：矩形框四角常过冲或没对上（0234），圆不正（0237 月亮）。
- **少量面**：填色是块状且不贴线（0237 黄色、0205 葡萄紫色涂抹），像“先画线后涂色，涂出界”。

## 2. 简化程度 [J]

- 人物是火柴人或圆头 + 简单身体（0238、0248、0259），无五官或只有点眼。
- 物件只保留识别必需的轮廓：树 = 一团云 + 两根线（0322），手机 = 圆角矩形（0295）。
- **为什么随意但完成度高**：（1）元素少，每一笔都承担意义；（2）线粗与线色全画面统一；（3）位置精确——小人刚好推着杯子、倚着手机角，**关系精确而形态随意**。随意的是形，不随意的是构图与情节。

## 3. 实拍 + 手绘结合方式 [J]

| 方式 | 样本 |
|---|---|
| 手绘角色对真实物体施加动作（推、举、跳上） | 0248, 0237, 0238 |
| 手绘物件把材料“倒进”真实产品（虚线滴落） | 0029, 0235 |
| 手绘框框住照片 | 0234 |
| 白线涂鸦覆盖在街景照片上 | 0259 |

共同点：照片保持真实，不加滤镜；手绘不模仿照片的透视和光影，两套真实并置产生幽默。

## 4. 拟人化程度 [J]

拟人通常只加**肢体**（手、腿），很少加脸（0237 杯子长出手臂）。避免卡通大眼和笑脸——这是区分“喜茶式拙趣”和一般可爱插画的关键。

## 5. 实现

zhuoqu/doodle.py：用平滑 1D 噪声沿路径法向位移生成手绘线（stroke 宽度恒定、圆头），提供小人、杯子、手、箭头、虚线滴落、抖动框、划改线、云、树、太阳、月亮等原语；原语只是词汇，由规划器根据情节组合。有图像模型时，复杂插画交给模型，原语用作草图或叠加线。
