# 构图系统

> 证据等级：**[M]** 像素测量（zhuoqu.analyze，可复现）；**[J]** 设计判断（可复核）；**[S]** 主观审美推断（需人工校准）。样本编号见 data/manifest.jsonl；语义标注为 agent_assisted / review_required。

## 2. 典型构图（策略，不是模板）[J]

| 策略 | 样本 | 结构 | 何时用 |
|---|---|---|---|
| subject_center 主体居中 + 小标题 | 0237, 0029, 0235 | 主体占画面 25–40%，标题在上方或分列两侧 | 单一产品、节日 |
| subject_offset 主体偏置，文字配重 | 0238, 0248, 0201 | 主体在一侧三分线，文字在对角 | 有动作/方向感的情节 |
| negative_space 大面积负空间 | 0322, 0201, 0190 | 内容 <20% 面积，压到一角或一条带 | 安静、发呆、慢 |
| lettering_lead 手写标题主导 | 0012, 0009, 0114 | 文字是最大元素，竖排或分组 | 讲一个想法、产地故事 |
| photo_lead 产品摄影主导 + 手绘点缀 | 0029, 0235, 0248 | 实拍为主体，线稿负责动作 | 有产品照片时 |
| drawn_frame 手绘框 | 0234, 0295 | 抖动矩形/手机轮廓框住照片或文字 | 清单、故事、“记录” |
| info_card 轻量信息卡 | 0104, 0247 | 规整小字块放角落或底部 | 活动、日期、地址 |

## 3. 疏密与比例规律 [J]

1. **一个焦点**：画面只有一个最大物；第二大元素面积通常不到它的一半。
2. **文字与主体不重叠**：主线样本中手写标题与主体之间留有至少约半个字高的间隙；只有“文字与插画互动”时（0237 杯子举月、0201 划改）才刻意接触。
3. **留白是有方向的**：留白集中在一侧/一条带，而不是均匀分散在四周（0238 右上大空、0201 左侧大空）。
4. **安全边距大**：内容距画布边缘通常 ≥8% 短边。
5. **质心近中，元素偏置**：全数据质心中位 (0.50, 0.51) [M]——偏置构图依赖文字与主体互相平衡。

## 4. 程序实现

zhuoqu/layout.py 把策略表达为参数（主体框、标题框、信息框的相对坐标 + 抖动范围 + 冲突约束），由规划器选择，再按 seed 在区间内求解；validate.py 检查遮挡、边距、留白和对比度。
