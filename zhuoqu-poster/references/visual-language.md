# 喜茶视觉语言（2025H2–2026）

> 证据等级标注：**[M]** 可测量（来自 `zhuoqu.analyze` 的像素测量，可复现）；**[J]** 设计判断（基于样本观察，可被他人复核）；**[S]** 主观审美推断（需人工校准）。
> 样本编号指 `data/manifest.jsonl` 中的 id。所有语义标注目前为 agent_assisted / review_required，未经人工审核前不应视为事实。
> 数据集：354 张采集，154 张保留（详见 README 的数据统计）。测量统计用中位数。

## 0. 先说结论：不是一种风格

样本里至少有四套彼此独立的语言，不能混为一谈：

| 系 | 时期 | 样本 | 测量特征 [M] | 判断 [J] |
|---|---|---|---|---|
| A. 拙趣手绘 / 灵感手记 | 2025H2 起为主线 | 0009–0012, 0029, 0234–0238, 0247, 0248, 0295, 0322 | 留白 0.70–0.90，边缘密度 0.02–0.05，色彩丰富度 6–30，文字面积 0.03–0.15 | 本 Skill 的主要学习对象 |
| B. 草台班子 / 工地围挡 | 2025-11, 2026-04 | 0114, 0190, 0197, 0200–0204, 0245 | 留白中位 0.39（实景墙面），色彩丰富度 17 | 手写 + 错字 + 涂改作为笑点；场景即画布 |
| C. 联名 IP / 节日 | 2025-12 Starman、2026-02 CNY 马、2026-04 Hello Kitty | 星星人 13 张，马 10 张，芭乐 6 张 | Starman 留白 0.75 但色彩 42；CNY 色彩 50.6 | 由 IP 方决定造型；喜茶只保留“大留白 + 少元素”的版式纪律 |
| D. 2019–2020 复古国潮 / 土味 | 历史 | 0303–0319, 0130–0141, 0225–0228 | 留白 0.28–0.35，边缘 0.085–0.113，色彩 45–47，文字面积 0.10–0.11 | **反例**：密、满、装饰多；用于对照，不作为生成目标 |

A 与 D 的测量差异是全数据里最清楚的信号：A 的边缘密度约为 D 的 0.4 倍，文字面积约为 D 的 0.5 倍，留白约为 D 的 2 倍 [M]。这说明近年的“拙”并不是“多画点涂鸦”，而是**做减法之后剩下的那一笔是手画的**。

## 1. 长期稳定的语言（跨活动重复出现）

1. **纸面感的背景**：主背景是带一点暖灰/米色的白，而不是纯白。例：0237 #f3f0e8、0234 #f7f7f3、0236 #f2efe6、0238 #f9f9f9 [M]。纯白主要出现在 App 截图框（0009/0010 的 #ffffff 来自 UI）。
2. **一根黑线 + 一个颜色**：线稿用近黑（0238 #060505、0043 #0f0e0d），再配一个强调色：0236 橙 #ed5d12、0237 蓝 #286478 + 黄、0009 柿子橙 #da7e32、0029 粉 #f3d3d8 [M]。四色以上的主题出现在联名与节日，不在主线。
3. **元素数量极少**：一个主体 + 一行（或两行）手写字 + 至多一个小点缀（0234 的小蜜蜂、0322 的倒杯、0295 倚靠手机的小人）[J]。
4. **文字小**：主线样本的文字框面积占比 0.03–0.08；“标题”通常比一般海报小得多，靠位置与留白获得注意力 [M]。唯一例外是“字即画面”的作品（0114 文字面积 0.58、0012 0.15）。
5. **视觉质心接近中心但主体常偏置**：全数据质心 x、y 中位 0.50/0.51 [M]；偏置作品通过文字与主体互相配重（0201 质心 x=0.74 是长围挡上把内容压到一侧的极端例子）。
6. **实物 + 手绘的“两种真实”**：真实产品照片保留材质，手绘只负责动作、情节或标注（0029、0235、0248）[J]。
7. **手写品牌句**：“new style tea by inspiration / 灵感之茶”反复以手写小字出现在门店墙、围挡、海报角（0201, 0204, 0322, 0328, 0331）[J]。

## 2. 只属于某次活动的特征（不要泛化）

- 草台班子的错字与划改（0201 “coming soon → slowly”、0190 “为呈现更好的喜茶”配梯子）：笑点依赖“施工中”语境 [J]。生成器只在主题涉及“未完成 / 筹备 / 慢一点”时才启用“可见修改”策略。
- CNY 马的儿童彩铅（0270–0274）：创意核心是“名人亲手画的不熟练的马”，作者身份就是创意。普通任务模仿彩铅涂抹没有这层意义 [J]。
- Starman / Hello Kitty 的 IP 造型：受版权保护，禁止复刻。
- 2020 夸夸瓜的描边大字、点赞剪贴画：刻意土味，属于另一套语言。

## 3. 色彩如何随主题变化

| 主题 | 观察 | 证据 |
|---|---|---|
| 产地 / 原料故事（柿子、龙井、牛肝菌） | 背景近白，强调色直接取自原料实拍（柿橙、茶绿、菌褐） | 0009, 0234, 0029 [M] |
| 节日（中秋、春节） | 中秋：冷蓝线 + 暖黄单点；春节：大面积红但只用于包装实物 | 0237, 0266–0269 [M] |
| 口味抽象化 | 色块即味道，几乎无线条 | 0236（边缘密度 0.013，色彩 74）[M] |
| 门店 / 空间 | 低饱和水泥、浅木、白墙；色彩丰富度 19–24 | jinsha, one_avenue [M] |
| 联名 IP | 高饱和，但仍保留大留白 | starman 留白 0.75 / 色彩 42 [M] |

规律 [J]：**色彩来自题材本身**（产品、原料、节令），而不是一套固定品牌色；统一感来自“米白底 + 近黑线 + ≤2 个题材色”的比例关系。

## 4. 哪些可以程序化，哪些需要模型

| 特征 | 实现 |
|---|---|
| 背景纸色、色数上限、强调色比例、留白下限、文字面积上限、安全边距 | 确定性代码（configs/styles.yaml 约束 + validate.py 检查） |
| 准确中文、功能信息层级、手写字形的节奏性扰动 | 确定性代码（typography.py） |
| 单线条简笔物件、波浪框、箭头、虚线滴落、划改线 | 确定性代码（doodle.py，低频噪声驱动的笔触） |
| 有情节的插画（人物动作、拟人表情）、产品质感、背景氛围 | 图像模型（当前环境无可用服务 → 降级为程序化简笔 + 用户提供照片） |
| 创意概念、隐喻选择、文案语气 | LLM / 规划器（当前为规则 + 策略库，可接入 LLM） |
